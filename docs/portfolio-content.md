## 5. Workflow Process

Each stage is two short lines on the page. Stage 4 names the AI-assisted part of the workflow (supported by the Design & AI skills rows in section 4).

1. **Research & Discovery** — *Technical Scope Definition.* Define the technical scope, target users and edge-case business logic before any code. *Requirement Analysis, Domain Modeling, Use Case Mapping.*
2. **Analyze & Model** — *Architectural Blueprinting.* Turn requirements into normalized MSSQL/MySQL schemas and secure REST endpoint plans. *MSSQL, MySQL, Relational Databases, API Design.*
3. **System Design & UI** — *Interface & Component Engineering.* Wireframe in Figma, then build accessible, modular Angular, TypeScript and Tailwind components. *Angular, TypeScript, Tailwind CSS, Figma, UI/UX Design.*
4. **Full-Stack Development** — *Backend Logic & Integration.* Build C# and .NET Core services with Entity Framework and ThingsBoard integration, drafting and reviewing with AI assistants (Claude, Gemini). *C#, .NET Core, ASP.NET Core, Entity Framework, ThingsBoard, IoT Telemetry, AI-Assisted Dev.*
5. **Quality Assurance** — *Testing & Version Control.* Unit, regression and exploratory testing, with branching and pull requests in Azure DevOps. *Unit Testing, Software Testing (QA), Azure DevOps, Git Control.*
6. **Launch & Optimize** — *Deployment & Monitoring.* Ship through automated Git pipelines, then watch logs, SQL performance and live telemetry. *Microsoft Azure, AWS, CI/CD Pipelines, System Monitoring.*
